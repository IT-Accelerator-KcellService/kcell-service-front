# Руководство по импорту повторяющихся задач через Excel

## Обзор

Функционал импорта повторяющихся задач через Excel позволяет создавать множество повторяющихся задач одновременно, загружая Excel файл с данными.

## Доступность

Функционал доступен только для пользователей с ролями:
- `admin-worker`
- `department-head`

## Как использовать

### 1. Доступ к функционалу

1. Войдите в систему с соответствующей ролью (`admin-worker` или `department-head`)
2. Перейдите на страницу вашей роли:
   - Для `admin-worker`: `/admin-worker`
   - Для `department-head`: `/department-head`
3. Найдите кнопку "Импорт Excel" рядом с кнопкой "Создать заявку" в верхней части страницы

### 2. Скачивание шаблона

1. Нажмите кнопку "Импорт Excel"
2. В открывшемся модальном окне нажмите "Скачать шаблон"
3. Откроется Excel файл с примером данных

### 3. Подготовка данных

Excel файл должен содержать следующие столбцы:

| Столбец | Описание | Обязательный | Пример |
|---------|----------|--------------|---------|
| Название | Название повторяющейся задачи | Да | "Ежедневная уборка" |
| Описание | Подробное описание задачи | Нет | "Уборка офисных помещений" |
| Локация | Место выполнения задачи | Да | "3 этаж, кабинет 305" |
| Категория | Категория услуги | Да | "Уборка" |
| Тип_повторения | Частота повторения | Да | "daily", "weekly", "monthly", "yearly" |
| Интервал | Число периодов | Да | 1, 2, 3, 4, 6, 12 |
| Дата_начала | Дата начала выполнения | Да | "2024-01-15" |

### 4. Правила валидации

#### Название
- Минимум 3 символа
- Не может быть пустым

#### Локация
- Минимум 3 символа
- Не может быть пустым

#### Категория
- Должна существовать в системе
- Регистр не учитывается

#### Тип_повторения
Допустимые значения:
- `daily` - ежедневно
- `weekly` - еженедельно
- `monthly` - ежемесячно
- `yearly` - ежегодно

#### Интервал
- Число от 1 до 365
- Определяет, через сколько периодов повторяется задача

#### Дата_начала
- Формат: YYYY-MM-DD
- Не может быть в прошлом
- Пример: "2024-01-15"

### 5. Загрузка файла

1. Подготовьте Excel файл согласно требованиям
2. Нажмите "Выберите файл" или перетащите файл в область загрузки
3. Поддерживаемые форматы: `.xlsx`, `.xls`
4. Максимальный размер: 10MB

### 6. Результаты импорта

После загрузки файла вы увидите:

#### Статистика
- **Успешно** - количество созданных задач
- **Пропущено** - количество пустых строк
- **Ошибок** - количество строк с ошибками

#### Ошибки
Если есть ошибки, они будут показаны с указанием:
- Номера строки
- Списка ошибок для каждой строки

## Особенности

### Ролевые ограничения

- **admin-worker**: Создает задачи от своего имени
- **department-head**: Создает задачи для своего офиса

### Автоматическое создание экземпляров

После создания повторяющейся задачи:
1. Создается первый экземпляр на указанную дату начала
2. Система автоматически создает новые экземпляры при выполнении предыдущих
3. Экземпляры создаются согласно типу повторения и интервалу

### Статусы задач

- **pending** - ожидает выполнения
- **completed** - выполнено
- **overdue** - просрочено
- **skipped** - пропущено

## Устранение неполадок

### Частые ошибки

1. **"Категория не найдена"**
   - Проверьте правильность названия категории
   - Убедитесь, что категория существует в системе

2. **"Неверный формат даты"**
   - Используйте формат YYYY-MM-DD
   - Пример: "2024-01-15"

3. **"Дата начала в прошлом"**
   - Установите дату начала не раньше сегодняшнего дня

4. **"Файл слишком большой"**
   - Уменьшите размер файла до 10MB
   - Удалите лишние строки

### Поддержка

При возникновении проблем:
1. Проверьте формат данных согласно требованиям
2. Убедитесь, что все обязательные поля заполнены
3. Проверьте правильность названий категорий
4. Обратитесь к администратору системы

## Технические детали

### Поддерживаемые форматы файлов
- Microsoft Excel (.xlsx)
- Microsoft Excel 97-2003 (.xls)

### Ограничения
- Максимальный размер файла: 10MB
- Максимальное количество строк: не ограничено
- Кодировка: UTF-8

### API Endpoint
```

Content-Type: multipart/form-data
```
